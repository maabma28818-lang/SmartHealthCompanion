Smart Health Companion

A web-based healthcare application designed to assist users in managing their health efficiently. 
The system provides features like symptom-based disease prediction, doctor search, appointment booking, and AI-powered medical assistance.

Features :

Symptom-based Disease Prediction (AI-powered)
Doctor Finder
Appointment Booking System
Patient and Doctor Dashboard
Notifications System
Medical Image Analysis (AI-based)
Secure User Authentication

Tech Stack :

Frontend: HTML, CSS, JavaScript
Backend: Python (Flask)
Database: SQLite
AI Integration: Groq API


Project Setup :

1)Clone the repository,
git clone https:https://github.com/maabma28818-lang/SmartHealthCompanion.git

2)Navigate to the project folder,
cd SmartHealthCompanion

3)Create virtual environment,
python -m venv venv

4)Activate virtual environment,
venv\Scripts\activate

5)Install dependencies,
pip install -r requirements.txt

6)Run the application,
python main.py

Environment Variables :

Create a .env file and add your API key:
GROQ_API_KEY=your_api_key_here
